Task 28 – Simple Percentage Analysis

Project Overview

This project is part of my Data Analytics Internship at Veda Technology.

The objective of this task was to calculate the percentage contribution of each product category to total sales using Microsoft Excel. I created a percentage table and charts to make the category-wise sales distribution easier to understand.

This exercise helped me practise percentage calculations and learn how they can be used to present business data clearly.

Objective

- Calculate total sales by category.
- Find each category's contribution to overall sales.
- Present the calculations in a percentage table.
- Create charts to compare category sales.
- Verify that the contribution percentages add up to approximately 100%.

Tool Used

- Microsoft Excel

Dataset

The workbook contains illustrative sales totals for three categories:

- Furniture
- Office Supplies
- Technology

Note: The current workbook uses sample practice values. These should be replaced with actual category totals if the task requires calculations from the Superstore dataset.

Calculation Method

The percentage contribution is calculated using the following formula:

Percentage Contribution = (Category Sales / Grand Total Sales) × 100

For example, if a category contributes ₹20,000 to total sales of ₹1,00,000:

Percentage Contribution = (20,000 / 1,00,000) × 100 = 20%

The denominator is the grand total of sales for all categories included in the analysis.

Work Completed

1. Category-wise Sales Table

Prepared a table containing category names, total sales, and percentage contribution.

2. Percentage Calculation

Used Excel formulas to divide each category's sales by the grand total.

Example formula:

=B2/$B$5

The result is formatted as a percentage.

3. Charts

Created two visualizations:

- Column Chart: Compares sales values across categories.
- Pie Chart: Shows each category's share of total sales.

4. Total Verification

Checked that the percentage contributions add up to approximately 100%, allowing for minor rounding differences.

Key Learning

Through this task, I practised calculating percentage contributions and presenting sales data in a clear format.

I also learned why it is important to identify the denominator before interpreting a percentage. The same category value can represent different contributions depending on the total used for comparison.

Interview Questions

1. What does percentage contribution mean?

It represents the share of a category in the overall total, expressed as a percentage.

2. Why must the denominator be stated?

The denominator defines the total against which the category is compared. Without it, the percentage may be unclear or misleading.

Conclusion

This task provided practical experience in Excel-based percentage analysis and data visualization. The percentage table and charts make it easier to compare category-wise sales and understand each category's contribution to the overall total.
